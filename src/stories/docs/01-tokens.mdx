### Spacing & typography

- Spacing: `--epaper-space-1 … --epaper-space-8` (4px base)
- Type: `--epaper-text-xs … --epaper-text-4xl`; line heights `--epaper-leading-*`
- Fonts: `--epaper-font-sans`, `--epaper-font-serif`, `--epaper-font-mono` (system stacks)
- Focus: `--epaper-focus-width`, `--epaper-focus-offset`
- Measure: `--epaper-measure`, `--epaper-measure-narrow`, `--epaper-measure-wide`

### Borders & radius

`--epaper-border-thin` (1px) · `--epaper-border-medium` (2px) · `--epaper-border-thick` (3px) · `--epaper-radius-sm|md`.

### Theme preview

```html
<div data-theme="default">…</div>
<div data-theme="inverted">…</div>
<div data-theme="high-contrast">…</div>
```

Tokens source: `demo/epaper-components.tokens.css`. Override per-surface if needed (e.g., nested `data-theme` on a card).
