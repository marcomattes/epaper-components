### Spacing & typography

- Spacing: `--eink-space-1 … --eink-space-8` (4px base)
- Type: `--eink-text-xs … --eink-text-4xl`; line heights `--eink-leading-*`
- Fonts: `--eink-font-sans`, `--eink-font-serif`, `--eink-font-mono` (system stacks)
- Focus: `--eink-focus-width`, `--eink-focus-offset`
- Measure: `--eink-measure`, `--eink-measure-narrow`, `--eink-measure-wide`

### Borders & radius

`--eink-border-thin` (1px) · `--eink-border-medium` (2px) · `--eink-border-thick` (3px) · `--eink-radius-sm|md`.

### Theme preview

```html
<div data-theme="default">…</div>
<div data-theme="inverted">…</div>
<div data-theme="high-contrast">…</div>
```

Tokens source: `demo/eink-ui.tokens.css`. Override per-surface if needed (e.g., nested `data-theme` on a card).
