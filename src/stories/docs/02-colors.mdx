### Error & disabled roles

- Error: `--eink-error-fg`, `--eink-error-border`, `--eink-error-bg`
- Disabled: `--eink-disabled-fg`, `--eink-disabled-bg`, `--eink-disabled-border`

### Selection & highlights

- `::selection` uses `--eink-selection-bg`
- `<mark>` uses `--eink-mark-bg`

### Guidance

- Prefer borders and whitespace over large fills to reduce ghosting.
- For app-level theming, set `data-theme` on `<html>`; for scoped widgets, wrap in a `div data-theme="…">`.
