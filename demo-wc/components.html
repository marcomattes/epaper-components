Form controls

Web Component wrappers for inputs reuse the same CSS classes and zero-specificity tokens. Attributes like disabled, aria-invalid, and type reflect onto the native control.

Select

Native dropdown UI is retained for best E-Ink performance. Arrow indicator is drawn with CSS gradients—no SVG assets.

Checkbox & Radio

Indicators are border-based (no shadows) to avoid ghosting on partial refresh. States mirror checked, disabled, and aria-invalid.
